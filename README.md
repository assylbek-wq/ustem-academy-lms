# USTEM Academy

LMS для подготовки учителей инженерного образования: робототехника, FIRST, дроны, космос, 3D, ИИ.
Учитель проходит онлайн-модули, приходит на очный интенсив, проводит урок в своем классе, загружает видео,
получает разбор наставника по рубрике и сертификат с QR-кодом.

Стек тот же, что у USTEM Connect: **Flask + Jinja2 + Tailwind**, серверный рендеринг, без сборки фронтенда.
База: **PostgreSQL** в продакшене, SQLite для локальной разработки. Интерфейс на казахском, русском и английском.

> Предыдущая статичная версия (HTML + LocalStorage) сохранена в истории под меткой `legacy-static`.

## Быстрый старт (локально)

```bash
pip install -r requirements.txt
SEED_DEMO=1 python wsgi.py          # http://localhost:5080
```

Демо-аккаунты (пароль у всех `demo12345`, создаются только при `SEED_DEMO=1`):

| Роль | Email |
|---|---|
| Администратор | admin@academy.demo |
| Методист | methodist@academy.demo |

## Что умеет MVP

| Роль | Возможности |
|---|---|
| Учитель | Мои программы, план когорты, уроки (видео, текст, Markdown), тесты с пояснениями, загрузка видео частями с докачкой, история попыток, комментарии наставника по таймкодам, сертификаты PDF с QR, портфолио с публичной ссылкой, ИИ-помощник в уроке |
| Наставник | Очередь проверки (сначала давние), плеер с комментариями по таймкодам, рубрика 1-4, решение «принять» или «на доработку» |
| Мастер-тренер | Свои когорты, прогресс каждого слушателя, назначение наставников, посещаемость с телефона с офлайн-очередью |
| Методист | Студия: программы, уровни, модули, уроки, тесты, задания, рубрики на трех языках, материалы, предпросмотр, публикация версий |
| Администратор | Когорты, занятия, слушатели, импорт из Excel/CSV, приглашения, пользователи и роли, заказчики, сертификаты (выдача, отзыв), заявки с сайта, журнал действий |
| Заказчик | Отчеты только по своим когортам, выгрузка в Excel, печать в PDF |
| Публично | Каталог программ, запись в открытую когорту по ссылке, заявка от школы или акимата, проверка сертификата по номеру или QR, бейдж в формате Open Badges |

**Правило завершения уровня:** пройдены все уроки и тесты (не ниже проходного балла), наставник принял все
задания, слушатель был на всех очных интенсивах когорты (если включено). Тогда сертификат выдается сам.

## Каталог программ

При первом запуске создаются «Основа USTEM» и **FLL Future Edition, уровень «Старт»** (уроки, тест, задание,
рубрика из 5 критериев), а также черновики остальных направлений: FTC, Battle of Bots, Physical AI,
Alem Drone League, WSO, Future Race, FLL Challenge и FLL Explore (Founders Edition). Методисты наполняют их в студии.

## Настройки (переменные окружения)

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | `postgresql+psycopg://user:pass@host/db`, по умолчанию SQLite `academy.db` |
| `SECRET_KEY` | обязательно задать в продакшене |
| `UPLOAD_DIR` | где хранить видео и материалы (на сервере в РК) |
| `PUBLIC_BASE_URL` | адрес сайта для ссылок в письмах и QR |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `MAIL_FROM` | почта. Без нее ссылки-приглашения видны админу в интерфейсе |
| `ANTHROPIC_API_KEY`, `AI_MODEL`, `AI_DAILY_LIMIT` | ИИ-помощник. Без ключа он скрыт |
| `MAX_UPLOAD_MB` | лимит видео, по умолчанию 2048 |
| `SEED_CONTENT` / `SEED_DEMO` | каталог программ / демо-данные при первом запуске |

## Деплой на VPS (ps.kz)

```bash
bash deploy/setup-vps.sh academy.ustem.kz assylbek@ustemfoundation.org
```

Скрипт ставит PostgreSQL, Caddy с HTTPS, systemd-сервис на порту 8010 и ежедневный бэкап базы.
Можно ставить на тот же сервер, что и USTEM Connect. Обновление: `bash /opt/ustem-academy/app/deploy/deploy.sh`.

## Разработка

```bash
python -m unittest discover tests -v                     # SQLite
TEST_DATABASE_URL=postgresql+psycopg://... python -m unittest discover tests -v
bash deploy/build-css.sh                                 # после правки классов Tailwind
```
